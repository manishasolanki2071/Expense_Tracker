# 💰 Personal Expense Tracker

A sophisticated financial management application designed to help users track their daily income and expenses effortlessly. Built with modern web technologies, this tracker offers an intuitive interface for managing personal finances with real-time updates and data persistence.

> Smart money management at your fingertips!

## 🌐 Live Demo

[View Demo](https://manishasolanki2071.github.io/Expense_Tracker/)

## 🎯 Overview

This expense tracker simplifies personal finance management by providing:

- 📊 Real-time balance tracking
- 💸 Easy income & expense management
- 🔍 Smart filtering system
- ⚡ Lightning-fast performance
- 📱 Fully responsive design
- 🔄 Data persistence using LocalStorage
- 📋 Transaction history with sorting options

## 🛠️ Tech Stack

- **Frontend**: HTML5, TailwindCSS for modern UI
- **Logic**: Vanilla JavaScript
- **Storage**: Browser LocalStorage
- **Performance**: Optimized for quick interactions
- **Design**: Responsive & Mobile-first approach

## ✨ Key Features

### 💳 Transaction Management

- Add transactions with detailed remarks
- Categorize as income or expense
- Delete entries with single click
- Filter by transaction type
- Smart sorting by amount/remarks

### 📊 Smart Dashboard

- Real-time balance updates
- Color-coded transaction cards
- Interactive data visualization
- Responsive data tables
- Clean, modern interface

### 🔄 Data Handling

- Automatic data saving
- Offline functionality
- No registration required
- Easy data reset option
